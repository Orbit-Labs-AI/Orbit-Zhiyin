# Orbit 宣传片分镜

全片 120 拍，124 BPM，1 拍 = 0.484 秒，共约 58 秒，1920×1080，纯黑底。表中「拍」是 `promo.js` 与 `music.py` 共用的时间轴，「秒」是成片时间码。

## 画面语法

- **组件特写**：每个镜头只显示 App 里的一个组件，其余隐藏。两份 App（A、B）轮流出镜，前一镜离场与后一镜入场交叠。
- **字体层级**：眉题用等宽字、字距加大、灰色；主标题用银色渐变粗体；副标题用 Orbit 冷灰蓝（`--acc` #9fb5bc）细体；正文用灰白细体。
- **转场**：不用闪白，也不用震屏。主要手法有四类：
  - 交叠缓动：上浮、纵深推拉、横移、倾斜平面放平。
  - 形状流变：数字飞进卡片，柱状图卷成罗盘，罗盘倾斜成轨道，再变成标志。
  - 同向运动：曲线、柱状图、轨迹都往右走；推荐、启示、工坊都往上走。
  - 真实交互：光标点击后，App 自己做出响应。
- **Orbit 母题**：片头光点绕轨道，然后画出标志。罗盘从倾斜的轨道视角翻正入场，五个 Agent 作为行星绕环带公转。片尾罗盘倾斜回轨道，标志在环带上重新画出。
- **轻重缓急**：
  - 缓：开场、标志、慢速介绍的三种人格、人格落定、片尾。
  - 中：概览、推荐、轨迹。
  - 急：12 型快速轮换、7 个功能每 2 拍一换。
  - 重：人格落定时花瓣收拢后重开、推荐计数落定的和弦。

## 数据来源

画面里的数字和文字都直接取自运行中的 App（`../tandem-demo.html`）：
- KPI、趋势、建议及其节省时间、轨迹、启示、生成工坊的内容；
- 16 型的名称与描述（`TYPES`）、维度极名（`AXES`）；
- 你的人格分值、24 小时 × Agent 的会话分布、协作重心。

罗盘与 App 的指南针表盘（`fp2SVG`）共用同一套几何：外框、玫瑰、指针长度 0.8 × 玫瑰半径。这套共享规格由「Lite/Advanced UI 协调与动效设计」和「16型人格名称」两个 session 一起确认。外环的连续环带和 Agent 行星由宣传片提出，App 同步采用。其余 12 型的分值、作息和重心是按代码字母生成的示意原型，只在快速轮换中出现。
