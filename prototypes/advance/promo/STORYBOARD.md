全片 **88 拍**，132 BPM（1 拍 = 0.4545 秒），**40.0 秒**，1920×1080，纯黑底。文中「b」都是**成片拍**：场景代码、`music.py`、`render.mjs --only` 共用这一套拍号，`SHIFT` 表全部为 0。

## 规则（每个场景都适用）

- 纯黑底；只拍单个组件，不出现完整 App 窗口；不做卡拍震屏、白闪、整屏铺色。转场用相互重叠的缓动，以及匹配剪辑（上一场的某个元素直接变成下一场的元素）。
- 文字层级：mono 眉题（`.eb`）→ 银色粗标题（`.hv.sv` / `.xl.sv`）→ 橙色强调行（`.lt.acc` 或 `<b>` 橙）。每行停到刚好读完就走：文字镜头约 1.2–2 秒，紧凑、连贯。
- 标志只用 `orbitSVG`（与 `docs/design/logo` 同一条螺旋），不重画、不改线宽，颜色 `MARK_INK`。
- 字体与 App 一致：SF Pro / PingFang SC、SF Mono，人格类型码用 SF Pro Rounded（`.tcode`）。
- 文案只描述产品能力，不出现个人数字（会话数、小时数、分值）。推荐的节省一律是占比：App 的 `recPct(id)` → `{ t: 协作时间占比 %, k: token 占比 %, … }`，显示用 `fmtPct`，不出现小时。
- **Agent 点永远是各家圆形标志**（`agBadge` / App 的 `agLogo`），不用纯色圆点。全片只有一套 Agent 点：共享层 **AGD**（`scenes/02-agents.js`）。罗盘自带的标志关掉（`drawCompass({ pl: 0 })`），由 AGD 骑在罗盘上画，这样从开场到结尾都是同 5 个点在移动，没有替换。
- 环境光只来自 `05-light.js`；场景里不再调用 `glowAt`。

## 共享 API（infra 实现，场景作者按此调用）

### (a) Agent 点层 AGD（`scenes/02-agents.js`）

舞台上新增 `<svg id="agd" viewBox="0 0 1920 1080">`（放在 `#orbit` 之后、`#fx` 之前），以及同层的 HTML 容器 `<div id="agdb">` 放气泡和输入框。每帧在 `applyCams` 和 `orbitAt` **之后**调用 `applyAgents(t)`（因为罗盘编队要读取 deck 2 当帧的相机）。

```js
AGD.ID   = ['cc', 'cx', 'gm', 'ds', 'cp'];                 // = AGID，下标 i = 0..4
AGD.NAME = ['Claude Code', 'Codex', 'Gemini CLI', 'DeepSeek', 'Copilot'];
AGD.key(b, form, o = {})      // 编队关键帧（成片拍）。从 b 开始，每个点按 E.inOut 用 o.dur 拍（默认 1.2）
                              // 从「当时的实际位置」（前一个编队实时求出的位置）移到新编队；o.stag：逐点错开（默认 .08 拍），
                              // o.arc：路径向上拱起的像素（默认 0），o.ease 可换缓动。编队按 b 排序，最近的一个生效。
                              // 混合是「活的」：pos = mix(旧编队(b), 新编队(b), e)，旧编队在混合期间继续按自己的公式运动（转圈、
                              // 跟罗盘相机），所以速度连续、不会先停再走。o.polar: [cx, cy]：按椭圆参数插值（见「转场关键帧」K0），
                              // 不走直线弦；ring / orbit / compass 之间的交接一律用它。
AGD.follow(b0, b1, fn, o = {})// 逐帧覆盖：fn(i, b) → { x, y, r, a } 或 null（null = 该点不覆盖）。优先级高于 key；
                              // o.blend（默认 .6 拍）：进入和离开时与底下编队交叉混合，不跳。
AGD.pos(i, b)                 // 该点在 b 时最终的 { x, y, r, a }（编队与 follow 都算过之后）——交接时读这个
AGD.link(b0, b1, i, to, o)    // 从点 i 到屏幕点 to（[x, y] 或 fn(b) → [x, y]）的连线，2px，三次贝塞尔（o.bend：水平切线长度，默认 .4）；
                              // o.draw：画出时长（默认 .35 拍，从点向外长），o.out：收回（默认 .3 拍，向点收回），
                              // o.color（默认该 Agent 的颜色 AGC[i] 与白各半，透明度 .7），o.pulse：沿线流动的亮点个数/拍（0 = 无）
AGD.bubble(i, b0, b1, text, o)// 锚在点 i 上的气泡（HTML .agb，跟着点走）：o.dx / o.dy 气泡尾巴相对点心的偏移（默认 0, −r−18，
                              // 气泡在点的正上方，尾巴指向点），o.kind：'ask'（创作 prompt，白字深色玻璃）| 'fix'（纠正指令，
                              // 白字，左侧琥珀色 ⟲ 小标，边框偏暖）；从点心放大弹出 .25 拍（E.back），离开时缩回点心 .2 拍
AGD.glow(i, b0, b1, v)        // 点背后一圈该 Agent 颜色的柔光（v 0..1，前后各 .3 拍缓入缓出）
AGD.chat(b0, b1, o)           // 输入框组件（见下）
```

编队 `form`（参数放在 `o` 里，坐标都是舞台 px，`r` 是标志半径 px，`a` 是不透明度）：

| form | 参数 | 每个点的位置 |
| --- | --- | --- |
| `'off'` | — | 在当前位置缩到 r·.4 并淡出（a → 0） |
| `'pts'` | `pts: [[x, y], ×5]`、`r`、`a`、`drift`（像素，默认 12） | 固定点，外加各自的慢速漂移（Lissajous，周期 9–14 拍，相位 = `hash01(i)`，不随节拍） |
| `'ring'` | `cx, cy, R, ph`（i = 0 的角度，度，0 = 正上方，顺时针），`spin`（度/拍），`r` | 角度 = ph + i·72 + spin·(b − 关键帧拍) |
| `'compass'` | `r`（可选，默认按罗盘缩放） | `cpBadge(i)`：罗盘上该 Agent 标志的位置（见 c） |
| `'column'` | `x, y0, gap, r`、`order`（可选：`[第 i 个点所在的行]`，或 `'y'` = 按关键帧那一刻各点的 y 排序） | (x, y0 + order[i]·gap)，不给 order 时 order[i] = i |
| `'row'` | `cx, y, gap, r`、`order`（可选，同上，`'x'` = 按 x 排序） | (cx + (order[i] − 2)·gap, y) |
| `'merge'` | `x, y, r` | 5 点重叠在 (x, y)：先以 ±12px 扇形错开，.4 拍内收拢为一；合并后只画最上面的 cc 标志，外围加一圈 5 段 Agent 颜色细环（r + 7，每段 72°，1.5px），表示「几个 Agent 合成一个」 |
| `'orbit'` | `cx, cy, rx, ry, ph, spin, r` | 倾斜轨道（椭圆）上，参数角 θ = ph + i·72 + spin·(b − 关键帧拍)，位置 (cx + rx·sin θ, cy − ry·cos θ)（θ 0 = 远端正上方，顺时针）；下半圈的点略大、略亮（近大远小 ±12%）。**远半圈（cos θ > 0）画在标志后面**：infra 在 `#orbit` 之前加 `<svg id="agdBack">`，远半圈的点画进去，近半圈画在 `#agd`；换层发生在 θ = 90° / 270°（x = cx ± rx），那里离标志至少 rx − .95R > 100px，不会看到跳层 |

预设点位（场景直接引用 `AGD.P.*`）：

```js
AGD.P.scatterA = [[360, 780], [470, 250], [1010, 170], [1530, 300], [1450, 830]];   // 1a，r 40
AGD.P.arc      = [[470, 600], [715, 520], [960, 492], [1205, 520], [1450, 600]];   // 1b / 1d，r 40（输入框上方的弧）
AGD.P.scatterC = [[180, 700], [260, 220], [960, 110], [1660, 220], [1740, 700]];   // 1c，r 30，a .55
```

三组预设都是**绕 (960, 540) 顺时针 cc → cx → gm → ds → cp**（方位角：scatterA 248 / 301 / 8 / 67 / 121°，arc 263 / 275 / 0 / 85 / 97°，scatterC 258 / 295 / 0 / 65 / 102°），与圆环、罗盘（18 + 72i°）同一个顺序，所以 1a → 1b → 1c → 1d → 1e 每一步都是径向伸缩，路径互不交叉（v17 初稿的 scatterA / scatterC 顺序不一致，会有两点交叉，已改）。

输入框 `AGD.chat(b0, b1, { x, y, w })` 返回 `c`：一个 App 风格的聊天输入框（深色玻璃圆角 28px、高 88px、左侧「+」、右侧橙色发送圆钮，字号 34px，占位字「给 Agent 发消息…」灰色），`b0` 起从下方 40px 升起淡入 .4 拍，`b1` 前 .4 拍下沉淡出。
- `c.type(b, text, dur)`：从 b 起逐字打出（匀速，光标闪烁按虚拟时钟），dur 拍打完。
- `c.send(b, i, o)`：b 时发送按钮按下（缩放 .9 → 1，.15 拍），框内文字清空，同一段文字以 `AGD.bubble(i, b + .15, o.until ?? b + 2, text, o)` 从点 i 弹出；框与点之间画一道 .3 拍的细光迹（白 40%，从框飞向点）。

### (b) 标志轨道（替换 `orbitAt` 里写死的 OPEN / CLOSE）

```js
markAt(b0, b1, fn)   // 在 [b0, b1) 内每帧调用 fn(p, b)，p = 段内进度 0..1；返回一个 orbitSVG 姿态，或姿态数组，或 null。
                     // 姿态 = { t0, t, yaw, pitch, R, cx, cy, a, head }，color 默认 MARK_INK。多个段重叠时都画（交叉淡换用）。
MARK.pose            // 当帧最后画出的姿态（只读），交接时可读
MARK.ICON = { yaw: 20, pitch: 45 }   // App 图标视角
MARK.TOP  = { yaw: 0, pitch: 90 }    // 俯视：外圈半径 = R（orbitPts 已按 r1 归一），内圈半径 = R·9/16
markRing(o)          // 便捷函数：{ cx, cy, R, grow, tilt, a } → 俯视/倾斜螺旋「从尾部长出」的姿态（t0 = 1 − grow·.999，t = 1，
                     // pitch = 90 − tilt，并按 v16 CLOSE 的 lift 修正让尾端落在 R 的圆上），开场 2 与收尾 6 共用
```

`orbitAt(bf)` 只剩：遍历 `markAt` 段 → `orbitSVG` 拼接 → 写入 `#orbit`。`OPEN`、`CLOSE`、`planetsSVG`、字标展开 `revealSVG` 在 v17 不再使用（infra 可以删，或保留不调用），`#hole1` 的遮罩不再使用。

### (c) 罗盘与 AGD 的交接（不跳）

- `drawCompass(st)` 新增 `st.pl`（罗盘自带标志的不透明度系数，默认 1）。v17 所有调用都传 `pl: 0`，罗盘只画表盘、轨道层、花，标志全部由 AGD 画。
- `drawCompass` 每次调用把 `st` 存到全局 `CPS`，并把每个 Agent 标志的计算位置（罗盘 800×800 坐标，含该层的 `spin` 旋转与 `collapse` 收拢后的半径 `lerp(r, 300, col)`）写入 `CPS.pl[i] = [px, py]`，按 `AGD.ID` 下标对应（`D.orb.planets` 里按 `x.a.id` 找；缺的 Agent 用 i·72° 的方位，r = 330）。
- `cpStage(px, py)`：罗盘坐标 → 舞台 px，按 deck 2 当帧相机（即 v16 `30-persona.js` 的 `proj`，搬进引擎）。
- `cpBadge(i)` = `{ x, y, r: 19·decks[2].C.s, a: 1 }`，由 `cpStage(...CPS.pl[i])` 得到。AGD 的 `'compass'` 编队每帧读它。
- 因为 `applyAgents` 在 `applyCams` 之后，罗盘相机怎么移（左移、缩放、倾倒成轨道），点都精确骑在外圈上；罗盘淡出（`dial`、`core` → 0）时点仍然有位置。进入罗盘时，`AGD.key(b, 'compass', { dur })` 从前一编队的实时位置缓动到 `cpBadge`；离开时下一编队从 `cpBadge` 的实时位置出发。罗盘 drive 在点需要读位置的整段内都要持续调用 `drawCompass`（哪怕表盘不透明度为 0）。
- 罗盘标志原本是降饱和色（`cpMute`）；AGD 用全色 `agBadge`，罗盘上同样用全色，以保持全片同一个点。

## 光影（`scenes/05-light.js`）

不再按段落一块块弹出。全片只有 **三团常驻光体**，每团在整部片里沿自己的连续路径移动：路径是经过下表路点的向心 Catmull-Rom 样条（位置、宽度、强度插值，速度连续，路点处不停顿），叠加现有的慢漂移与呼吸（周期 20–40 拍，不随节拍）。

独立性（v17 新增的硬约束）：
- 光体**不读取任何场景对象**（不调用 `AGD.pos`、`MARK.pose`、`elXY`、相机），路点全部手写在 `05-light.js` 里；它只是大致落在内容的空处或背后，不跟拍、不吸附。场景改动不会牵动光。
- 三团的路点**互相错开至少 1 拍**（除 b0 / b88 淡入淡出外，没有两团同一拍转向），且每团各有自己的匀速自转：A +.25°/拍、B −.18°/拍、C +.12°/拍（加在呼吸微转之上），所以三团从不同步转身。
- 相邻路点不能同位（向心 Catmull-Rom 在零长度段上参数退化）；每段速度 ≤ 75 px/拍（淡入段除外），光永远比内容慢，不会「追」着镜头跑。只在 b0–3 淡入、b85.6–88 淡出，中间不消失，只在路点间缓慢改变强度。「衍生」= 光体在原位、原尺寸上用 2 拍交叉溶解换成另一张图（形态演化），不跳位。透明度沿用 `GAIN 1.35`、上限 .7；内容最亮的段落（罗盘、推荐卡）把强度压到 .3 左右。

## 转场关键帧

本节给出每一次交接、每一次 Agent 点编队变化、每一次标志变形的精确关键帧，相邻两段的作者照这里的数字写，就能在像素上接上。上文各段表格已按本节改过；**两处不一致时以本节为准**。数字由 `promo.js` 的公式与 App 示例数据算出（罗盘标志半径来自 `compassData()`；换了演示数据要重算 r_i 一列，方位不变）。

### K0 约定与公式

- **方位角 B**：0° = 正上方，顺时针为正；点 = (cx + ρ·sin B, cy − ρ·cos B)。全片所有转动都是顺时针：圆环、轨道、罗盘各层、俯视螺旋从尾部长出的方向都一致，所以没有任何一次交接需要倒转。
- **圆环** `ring`：B_i = ph + 72i + spin·(b − 关键帧拍)。**轨道** `orbit`：参数角 θ_i 同式，位置 (cx + rx·sin θ, cy − ry·cos θ)，θ 0 = 远端；远半圈（cos θ > 0）在 `#agdBack`（标志后面）。轨道尺寸跟标志走：**rx = 1.6R、ry = .3R、cy = 标志 cy + .14R**（R = 标志 R；ICON 外框横向是 −.95R…+.81R，所以 rx − .95R ≥ 150px，换层处离标志很远）。
- **罗盘标志**（与数据无关的部分）：`buildCompass` 里 `k.ph[layer] = 72·layer + 18 − deg`，示例数据的层序就是 cc / cx / gm / ds / cp，所以第 i 个点的方位 **B_i = 18 + 72i + spin·SPIN[i]**（SPIN = 9 / 6.5 / 4.5 / 3 / 1.8 °/拍）。半径（罗盘单位，collapse 0）**r_i = 250.5 / 248.1 / 276.1 / 243.7 / 287.9**，collapse 1 时全部 = 300。deck 2 不倾斜时 `cpStage(px, py) = (ax + (px − 400)·s, ay + (py − 400)·s)`，标志半径 19·s。
- **`spin` 参数**：3 段用 **(b − 26.4)·.6**，6 段用 **(b − 72)·.5**（理由见各段；两段互不相连，各自独立取）。
- **polar 插值**（`AGD.key(…, { polar: [cx, cy] })`）：两端各取一个椭圆描述 {cx, cy, rx, ry, θ}——`orbit` 用自己的参数；其余编队（ring、compass、pts、row…）取该点相对 polar 中心的方位 B 与距离 ρ，记作 {cx, cy, ρ, ρ, B}。cx、cy、rx、ry 线性插值，θ 走带符号的最短差（wrap 到 (−180°, 180°]），位置 = (cx + rx·sin θ, cy − ry·cos θ)；r、a 线性。和普通 key 一样是活的：两端每帧都重新求值。
- **标志几何**：俯视（pitch 90）时尾端（t = 1）在半径 R、方位 **199.6° − yaw**，内端半径 9/16·R；尾部往里长的方向是顺时针。yaw 0 时 R 300 的尾端 = (859, 823)；yaw −160.4 时尾端在正上方。ICON（yaw 20, pitch 45）外框 = cx + [−.952, +.812]·R，cy + [−.744, +.614]·R。
