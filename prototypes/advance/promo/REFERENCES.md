# 参考片动效总结

yhyfhgs 推荐的四支发布片，2026-10-03 逐帧拆解（4 fps 总览 + 每个转场按原生帧率逐帧看）。完整逐镜表、帧图和每条手法的帧数都在本地 `.work/promo/study/`（不进仓库）：`apple-mac-studio.md`、`wastory-membrain.md`、`wastory-alpha.md`、`wastory-gwi.md`，以及上一版的复盘 `v6-critique.md`。

| 片子 | 时长 | 镜头 | 一句话特征 |
| --- | --- | --- | --- |
| Apple《The New Mac Studio with M5 Max and M5 Ultra》 | 80 s | 约 72 个，中位 0.45 s | 巨字逐词硬切累加，一种强调色（紫），主角前「急 → 断崖式静」 |
| What a Story × Membrain（销售 BI SaaS） | 70 s | 28 个，只有 5 个硬切 | 一个母题（渐变环形 KPI）贯穿全片，倾斜 3D 平面上的界面，乱序逐字显影 |
| What a Story × Alpha（加密资讯插件） | 60 s | 26 个，7 个硬切 | 母题生出内容，推进穿越，hero 段最慢最空，计数器先慢后快 |
| What a Story × GWI Spark（AI 助手） | 67 s | 38 个，7 个硬切 | 只用输入条、按钮、结果卡三样东西；固定句换词；logo 形状遮罩穿越；点击 bloom |

## 一、节奏

| 规律 | 出处 | 本片怎么用 |
| --- | --- | --- |
| 主角之前先快剪（每 2 秒 6 次以上变化），再断崖式静止 2–4 秒 | Apple 6–8 s、26–31 s | 指针快扫 + 四条证据快速锁定 → b44 落定后全片最静的揭晓 |
| 两个能量峰值都紧跟在长慢镜之后，并直接引出价值句 | Alpha 13 s、45 s | b44 人格落定、b79「省下 15.6% 的协作时间」 |
| 急的时刻 ≤ 0.5 秒，之后跟 1.5–3 秒的缓 | GWI | 每次点击、翻转、whip 都 ≤ 1 拍 |
| 同一种演示每重复一次就压缩一次 | GWI（演示 ①7.3 s → ③1.7 s） | 点击安装第一次完整、第二次只留按下；快剪段每项越来越短 |
| 主角只留一个组件、一个数字 | Alpha hero 段 | 人格段只有罗盘；推荐段只有总数 |
| 标题停留 ≈ 0.3 s × 词数 + 1.5 s；清单只表达「很多」，不要求读完 | Membrain、Apple | 中文按每秒 6–8 字 + 1 秒；建议卡传送带只要求读到数字 |
| 章节靠连接词卡或换色切开，不用交叉溶解 | Apple（AND / NOW / WITH） | 本片改用形状衔接，不用字卡（中文连接词卡太硬） |

## 二、转场

| 手法 | 机制（实测） | 出处 | 本片 |
| --- | --- | --- | --- |
| logo 形状遮罩穿越 | 星形洞放大并转 25°，16 帧 @60 fps，ease-in | GWI 10.5 s | 已有：Orbit 标志洞口下潜（保留）；新增：点击 bloom 处打开圆形穿越门 |
| 孔洞遮罩推入 | 圆形 clip-path 4 帧从 8% 扩到 140%，中段径向模糊 | Apple 17.9 s | 「建议 →」的穿越门 |
| 推穿（push-through） | 整体放大到 3.5–4 倍、外甩、模糊，0.8 s ease-in | Apple 8.9 s、Alpha 12.3 s | 沿情绪路面加速冲向消失点 |
| 形状 ↔ 组件 | 光点 → 胶囊 → 涟漪 → 工具条；字标外框收成芯片 | Alpha 39 s、Apple 5.8 s | 「186」碎成粒子 → 倾斜轨道 → 罗盘外框；芯片缩回玫瑰字母；圆环 → 螺旋 → 标志 |
| 环形穿越（scale-through portal） | 环保持线宽放大 6 倍穿过镜头，0.9 s ease-in | Membrain 16.1 s | 用在点击后的穿越门 |
| 卡内竖向换片 | 卡框不动，旧内容上滑出、新内容上滑入，8 帧 | Membrain 5.1 s | 「还有 ___」蒙太奇里的组件更替 |
| 沿平面轴斜推（传送带） | 倾斜平面沿自身对角方向推出、下一张同向推入 | Membrain 27–46 s | 轨迹 → 工坊 |
| 3D 翻转换卡 | rotateY 0 → 70°，侧面时换内容，再转回，共 12 帧 | Membrain 58.3 s | 建议卡翻成安装弹窗 |
| z 轴抬起 | 子卡沿法线抬起 + 阴影加深 + 放大 1.05，带回弹 | Membrain 38 s | 选中的建议卡、「有效」胶囊 |
| 2D → 3D 平面 + whip | 整屏缩成倾斜卡；绕 Y 轴快转出画，4 帧强运动模糊 | GWI 46.4–48.1 s | 工坊 → Ask |

| 色彩泛滥 / 色雾 | 背景瞬间铺满纯色或光斑 | Alpha 44 s、Membrain 10 s | **不用**：属于 v6 被否定的「过度反应」一类 |
| 1 帧闪回 | 新镜头第 2 帧插回旧镜头 1 帧 | Apple 3.25 s | **不用**：同上 |

## 三、文字

| 手法 | 机制（实测） | 出处 | 本片（`scenes/00-kit.js`） |
| --- | --- | --- | --- |
| 逐词硬切累加 | 每 5–12 帧加一个词，不淡入；行宽靠缩放撑满 | Apple D1 | `K.words`：片头「每天和 5 个 Agent 协作上百次」 |
| 积累式缩小为眉题 | 前提逐词读完后缩到 15% 上移，结论成巨字 | Apple D4 | `K.words` 的 `shrink`；揭晓块缩成右上角眉题 |
| 小前缀 + 巨数字 + 单位第二行，字重细 → 粗 | UP / TO 各 6 帧，数字 3 帧内跳到 Black | Apple F | 「协作时间 / 省下 **15.6** %」 |
| 超大首字缩回正文 | 首词 3–4 倍带模糊，6–8 帧缩回，其余词从右下飞入 | Alpha 37.8 s | `K.big`：「你是 怎样 协作的？」 |
| 固定句换词 | 竖向交叉 6–8 帧；或乱码 0.4–0.6 s 定形 | GWI D2 / D3 | `K.swap`：「你是 ___」「还有 ___」 |
| 乱序逐字模糊显影 | 每字随机延迟 0–0.5 s，模糊 8 → 0 | Membrain D1 | `K.blurIn` |
| 中心向外逐字显影 | 从中间字母向两侧，每字约 3 帧 | Membrain D2 | `K.centerOut`：DIMV |
| 乱码解码 | 每帧随机字形，0.3 s 后逐词锁定 | Membrain D3、Apple D11 | `K.scramble`：人格代码锁定 |
| 宽字距收拢 | 每字从 +0.6em、30% 不透明收紧，错开约 2 帧 | GWI D5 | `K.decode`：人格描述、Ask 回答 |
| 打字跟镜 | 11–15 字符 / 秒，镜头边打字边从 2.4 倍拉远并跟光标 | GWI C1 C2 | `K.type`：Ask 输入 |
| 数字滚动冲过头再回落 | 约 1 s ease-out，再回落 3 个点 | GWI D6 | `K.count(…, over)`：15.6% |
| 文字贴组件、同角度倾斜，左右交替 | 标签与 3D 平面同一 rotateX / rotateZ | Membrain D8 | `tag()`：轨迹、工坊 |
| 双词夹组件 | 两个同字号词分列组件两侧 | Alpha 30 s | Lite / Advance |
| 文字骑在数据上 | 小图挂在文字旁，随数据移动 | Apple E3 | 7 天进度标签、轨迹阶段标签 |

## 四、组件与数字

- **一个母题贯穿全片**（Membrain 的环、GWI 的 sparkle、Alpha 的球）。本片的母题是 Orbit 的轨道：开场行星落到标志线尾，标志洞口进入，「186」碎成粒子沿倾斜轨道变成罗盘，结尾光带收回成环、长成标志。
- **数字永远在过程里出现**：Membrain 的收益数字伴随折线上升，GWI 的数字冲过头再回落，Alpha 的计数先慢后快并推镜。本片：总数由每张建议卡的省时占比逐张飞入累加，最后冲过头回落到 15.6%。
- **四支片子都没有正面的 before → after**（Apple 用同版式重复做隐式对比，Membrain 只用上升曲线，GWI 没有效率数字）。这正是 Orbit 能超过它们的地方：本片用 App 自己的「效果追踪」——安装前后各 7 天、同一批项目——做一张全宽对比表，旧值划掉、新值滚动、绿色百分比弹出，最后给出「有效」。
- **操作演示**：光标 ease-out 移入 0.45 s → 停 0.15–1 s → 按下缩到 0.92 → 3 帧回弹（Membrain、GWI）。

## 五、v6 复盘（`v6-critique.md` 摘要）

| 问题 | v7 的处理 |
| --- | --- |
| 效率主线没有落点：计数停在 21.8 就淡出，22.7 从未停留；没有 before → after | 22.7 冲过头回落并停 ≥1.4 拍；新增安装 → 7 天 → 前后对比 → 巨字结论 |
| 人格揭晓只停约 1.5 s；名字比外缘代码先锁定，提前剧透；滚动时两个名字叠成乱码 | 四条证据逐个锁定字母，四个都锁定后才揭晓；名称槽一次只显示一个名字；揭晓文字可读约 2.7 s，DIMV 留到 b57 |
| 人格从哪来没有交代 | 数字 → 粒子落到表盘 → 四轴证据芯片（每会话 6.9 条消息…）→ 字母 |
| 人格与推荐没有因果 | 盲点「工具 / 环境失败 · 19 个会话 → 建议」直接打开推荐，安装的正是对应它的「重复失败熔断」 |
| 「左粗标题 + 右卡片」用了 9 次；3D 倾斜用了 6 次，界面小字都看不清 | 两者各最多 2 次；改用居中巨字、上下构图、放射构图、传送带、全宽对比表、固定句 + 下方组件 |
| 文字被组件遮挡（工坊标题、通知标题、旧组件墙残影） | 交接约定规定每段退场完成的拍点；标签只贴组件边缘 |
| 开场 3.8 s 黑场小字；Ask 段画面静止且音乐掉到 −20 dB；收尾 8 s 低能量 | 开场改为每拍一变的巨字；Ask 改为打字跟镜，律动不停；收尾压到 6 s |
| 峰谷错位：最快的是次要功能，主线结论在能量谷 | 两个 drop 放在 b44、b79 两个结论帧 |

## 六、保留的 v6 手法

洞口下潜、里程表数字、指针慢—快—慢长扫与光带鼓起、DIMV 衬线揭晓、安装弹窗上下构图、圆环 → 螺旋 → 标志收尾。这些在复盘里被列为有效，v7 只调时长不换做法。
