# Semantic Cascade：共享语义观察

此模块是显式运行的语义观察流程：先选择可用真人文本，再按预算解析，最后校验固定结构与引用，供 Instruction、Interaction、Preference 和主观 Outcome 复用。普通分析不会自动运行此流程；人工标注用于独立评价与校准，模型观察始终保留推断身份。

## 输入与边界

- 仅确认真人主会话的直接文本；平台块、代码块和引述按已有规范移除。子代理、重放、来源不明消息不进入候选。
- 每条直接文本最多 1,200 字符；最多两个同任务、严格在前的文本片段，合计 800 字符。超长或截断源明确列为未知，不在截断后假装完整理解。
- 默认每批最多 6 条、序列化候选最多 12,000 字符、最多 40 次调用、每次 60 秒、第一次失败即熔断。已接受的预算范围见 [candidates.py](candidates.py)。
- 固定 `gpt-6.1-sol` / `medium`；独立临时目录、只读沙箱、禁用 shell、apps、浏览器、代理委托、插件等能力，并拒用任何工具或未知活动输出。
- CLI 包装层不重试；CLI 内部的网络重试受外层总超时约束，不能声称内部重试次数为零。当前 CLI 没有已核实的服务端生成 Token 上限，输出结构/字节和时间限制不能冒充 Token 硬上限。
- 接收期间分别限制 CLI 事件流为 1 MiB、错误流为 64 KiB，超限即终止该进程组；最终 JSON 最多读取 64 KiB。输入通过临时文件传递，子进程不读取 stdin 也不会堵住包装层的超时。派生观察的作用域不变；这些是本地接收／接纳限制，不保证服务端生成 Token 或子进程瞬时文件写入量。
- 发送的请求仅含直接文本、同任务前文、角色和回答所需身份；时间、参数、工具结果、数据库、原始文件和输入哈希不发送。常见密钥移除不等于完全匿名，真实文本仍可能私密。

## 观察契约

[schema.py](schema.py) 使用禁止额外字段的固定结构。每条当前消息必须恰好出现一次；引用必须在当前直接文本中，目标必须位于同任务前文。条件不得丢失；假想反馈、问题、元语言与叙述不得升级成确认结果。

[pipeline.py](pipeline.py) 的缓存键覆盖模型、推理档位、提示词、Schema、预算、消息与前文、身份和时间。不同范围、历史内容或来源引用不能复用旧缓存。`available_at` 表示所用证据全部可见的时间，未知时间不补造；`generated_at` 独立记录实际计算时间。这是过去到未来重放的派生观察，不能用来回填人工标注的可见时间。

所有模型结果标为 `inferred` / `candidate`，校准概率为空。Instruction 的模型观察只供分析，不授予执行权限；Preference 复用同一 constraint_uid，形成任务范围的低优先级证据，与显式偏好和词面历史支持分别汇总；不提升为 global。Interaction 单列推断纠偏及目标未知数。主观反馈支持部分接受与返工，但不会把模型判断变成用户确认完成或客观成功。

## 显式运行与授权

先完成根 workspace 环境，并明确选择已有 canonical 数据。只筛选候选时运行：

```bash
uv run python -m evals.analytics.semantic_cascade --home /absolute/orbit-home --output .local/semantic-selection --dry-run
```

明确授权外发真实文本后，去掉 `--dry-run` 调用指定模型；输出必须位于忽略的 `.local/` 下。已有缓存可通过 `--cache .local/.../cache.json` 做纯本地分析，旧范围缓存会拒用。失败批次和未解析消息保留原因，不能变成零意图或零偏好。

构造的 [契约回归](../../../../tests/analytics/test_semantic_cascade.py) 验证引用、边界、降级、共享身份和权限不提升。这些回归不证明真实语义准确率；独立人工标签和模型服务可达性仍是外部实测条件。

本模块与 App AI service 的入口和授权流程分别维护，参见[AI 模块](../../../../../../docs/modules/ai/README.md)。新增版本同时更新缓存身份、引用反例和历史可见时间检查。
