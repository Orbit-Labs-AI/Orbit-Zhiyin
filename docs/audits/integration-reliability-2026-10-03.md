状态：本轮实现与验收记录；维护者：`yhyfhgs`。基线为 main `05049926`。本轮由 advisor 集成，GPT-6 Astra medium 负责导入与横切可靠性、high 分别负责分析/AI 和推荐/资源库。所有新增回归使用构造数据。

## 结论与范围

现有仓库不是仅有 UI demo：原生 macOS 宿主、HTTP/SSE gateway、两类 worker、canonical 数据链、八族分析、推荐、资源目录、AI 任务和安装/撤销都有真实实现。原来的模块接入表落后于代码，本轮已按入口和依赖重新整理，见[模块接入表](../architecture/module-map.md)。

本轮优先修影响结果的缺陷：会话漏发现和映射丢内容，空来源/单会话选择扩大范围，AI 缓存或证据校验绕过，资源验证信息丢失，设置竞态、问答串回答、补采派发假成功。新增能力沿用现有接口、队列、数据库和组件。没有新建平行分析框架，也没有给现有函数批量套用无必要的类或泛型。

## UI 修复与接线

| 问题 | 原行为 | 本轮行为 / 验证 |
| --- | --- | --- |
| 设置快速连点 | 旧响应或旧失败整体回滚较新的选择 | 同资源串行写入、叠加待提交选择；单次失败只回退相应请求；写入后旧 GET 不覆盖；构造先失败后成功回归 |
| 暂停采集缓存尚未加载 | 两个相同 pause 的响应各翻转一次状态，误报恢复 | 成功赋已请求的目标状态；补采的失败/重试由后端真实任务驱动 |
| 问答范围遗漏 | 未传当前时间、项目、来源、排除集和选中会话 | 打开问答时冻结范围，随请求交后端校验；空来源不扩大到全库 |
| 迟到的问答响应 | 旧问题可覆盖新问题，关闭后仍可能更新新弹窗 | 问题实例、弹窗实例与取消控制绑定；迟到 job 取消，轮询停止，不覆盖新答案 |
| 专业分析入口 | 只有通用问答 | 同一问答窗口可选协作与反馈、验证与交付、流程与工具、成本与时间；走现有 AI jobs |
| AI 推荐解释 | 新专家建议仅在 JSON 中 | 建议详情展示步骤、证据、局限和效果未测状态；转入生成工坊预填目标，不能直接安装 |
| 弹窗关闭 | footer 有“取消/完成”时不生成标题栏关闭图标 | 统一标题栏具名关闭按钮，保持 Esc、焦点回归 |
| 悬浮详情 | 只有隐藏整个组件或再次点击胶囊 | 增加收起详情按钮，保留胶囊并把键盘焦点还给胶囊 |
| 首次启动文案 | “0 B 上传”“不调用云端模型”与可选本地 Agent 模型配置不一致 | 以会话整理、协作分析、按需连接 Agent 为主，准确说明沿用 Agent 模型配置 |

专业模板产生的结论保留观察/假设区别、指标引用和分析局限；失败显示真实原因或经过验证的回退。现有生成工坊仍走上下文预览、任务、检查、产物、审阅/安装。推荐的 prompt 草稿转为规则定制，workflow 草稿转到已有 `generate.glue`。

## 不能由本轮自动检查替代的验收

- 七类已落盘协议覆盖与“这台机器所有 Agent 所有版本零遗漏”不同。尚未对真实来源逐文件与 Agent 自身历史清单对账；未落盘、已删和来源不可用内容无法恢复。
- 资源目录文本扩容、质量元数据评分与实际向量数量分开记账；默认离线构造验收没有下载 E5 权重或生成全量向量。详情见[推荐审计](recommendation-reliability-2026-10-03.md)。
- AI 专业模板、推荐专家与失败回退使用 fake runner/构造模型响应验证，没有把真实会话发给模型；需要单独标注集评价情绪、反馈、建议收益与长会话准确率。
- 未签名发布新版 App，未完成 macOS 原生安装包全部系统权限和窗口矩阵验收。内置浏览器看到的可运行页面与原生安装包是不同验收对象。
- 更新源、尚未落地的 Ollama 执行通道等现有边界仍明确保留；不把不可用操作描述成已实现。
