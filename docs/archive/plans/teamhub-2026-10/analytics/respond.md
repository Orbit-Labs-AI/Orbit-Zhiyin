## 范围

描述 agent 实际怎样回应和执行。调用成功只说明明确的调用范围，任务验收由 [Outcome 客观结果](<objective-outcome.md>)处理；耗时与用量汇总见 [Cost / Time](<cost-time.md>)。回滚、上下文重启有明确记录时保留，分叉先作为关系字段。

## 特征口径

| 字段 | 粒度／类型 | 定义与提取规则 |
| --- | --- | --- |
| `turn_count` | 会话 · 轮次数 | 按可识别的轮次边界计数，缺少边界时返回覆盖情况；一轮不等于一个任务。 |
| `tool_sequence` | 调用 · 有序记录 | 通过调用 ID 配对返回；调用及返回合计为一次调用，未配对项留待补全。 |
| `tool_result_status` / `failure_reason` | 调用 · 状态与原因 | 保存原始状态、结果范围与错误证据；包装脚本成功不能证明内部每一步成功。 |
| `retry_links` | 调用对 · 关系 | 结合任务、工具、参数摘要和结果范围确认重试；信息不足时只记候选。 |
| `subagent_relations` | 会话／代理 · 关系 | 记录可确认的父子 ID、启动、返回或汇合关系，不能由角色名猜测。 |
| `execution_intervals` | 调用／代理 · 时间区间 | 记录可靠起止时间、来源及质量；仅有日志时间差时标为估算，不判定实际并行。 |

## 分析函数

| 建议函数 | 输入 → 输出 | 主要处理 |
| --- | --- | --- |
| `pair_tool_calls(events)` | 有序事件 → 调用明细、结果及未配对项 | 按调用 ID 和来源配对，保留重复／缺失冲突证据。 |
| `analyze_execution_sequence(calls, turns)` | 调用与轮次 → 转移、成败、失败段及重试候选 | 区分流程统计和确认重试，明确状态分母及包装范围。 |
| `build_execution_relations(events)` | 执行事件 → 父子、重试及并行关系 | 优先显式关系与可靠时间，返回未决关系和缺失端点。 |

## 验收样例

- 一次调用有调用事件和返回事件：总调用数仍为 1；缺返回时状态不自动判失败。
- 同工具相邻失败，但参数摘要缺失：保留重复候选，不算确认的同参数重试。
- 两个调用记录相邻但无可靠起止时间：不能判定它们实际并行。
