# 前端-交互流程

> 历史来源：本页为2026-10-01 至 10-03 的历史方案，2026-10-07 从团队 Vault 迁入。原位置：`项目/Orbit/前端-交互流程.md`。正文与原有日期、结论保留，仅整理导航和空白；私人会话定位不公开。本文中的“当前”、TODO、测试数量和执行命令仅对原文基线成立，本次没有重新验证，也不自动形成任务或授权。现行入口：[源码文档](<../../../README.md>)。

两个模式：Lite和Advanced


1. 新用户下载，设置；和已有agent对接并识别
2. 开始分析，给出benchmark
	1. 可视化
	2. 分栏目设计
	3. 视觉重点：先下结论——模型人格



前端模块与功能
1. 概览
	1. 顶部筛选功能：7天、30天、90天、全部；Agent筛选；项目筛选。
	2. AI一句话解读+协作人格MBTI总结
	3. 会话个数、协作时长（可选）、发出消息数、纠偏率的数值统计
	4. 活跃节奏：按日的工作强度分布、每日工作时间分布。
	5. 工具调用/程序语言排行
	6. 本周工作建议
	7. 顶部导出与分享功能，同步按钮
2. 协作画像
	1. 四维人格画像的主图，大文字+会话分布的散点图。标签（可以搞怪）
	2. 逐月计算的人格趋势演变（最近几个月）
	3. 四个维度的数值分析信息
3. 会话与轨迹
	1. 上方显示时间轴，以及时间轴上排序的抽象出的任务(关键任务)，可缩放
	2. 左栏，会话按照最后聊天的时间进行时间排序。
	3. 右侧上面显示对话轮数、工具调用、错误或纠偏次数、tokens
	4. 启示：存在的问题与会话建议
4. 工具调用
	1. 工具调用次数、成功率、子代理
	2. 工具使用明细：工具名字+调用次数+错误率+平均耗时
	3. 调用链（转移矩阵）
	4. 失败原因
5. 项目分析（是否和会话与轨迹合并）
	1. 项目概览：对话轮次，时长，agent构成、对话人格
	2. 项目完成度vsToken使用数
	3. 规则与配置覆盖：agent.md、hooks、skills、MCP、子代理个数
6. 情绪与语义
	1. 词频统计，高频词（非语义bottleneck表示反馈语，语义画像表示兴趣点）
	2. 纠偏与摩擦类型统计
7. 优化建议
	1. 顶部栏放全部、prompt、skill、hooks、plugin/MCP、子代理、模型、workflow
	2. 按照推荐程度放各种优化配置推荐栏目，写明配置名称、适配agent，每个栏目右上角写预计效果，右下角预览并安装。点击以后各配置栏目收短至左侧，右侧放程序说明、预览（代码）、教程，右下角保留预览并安装，保留agent定制的按钮。
8. 资源库
	1. 最上方分：为你推荐、同人格正在用、热门
	2. 下方显示精选推荐，再下方是更多匹配。
9. 生成工坊（待定）


数据标准化+UI呈现的核对


需要量化的特征指标

各特征族的具体 TODO、特征口径与分析函数见 [分析模块分类](<analytics/classification.md>)，可进入对应文档认领和完善。

| 特征族                     | 当前需要的特征                                                 | 暂缓或按需保留                                     | 对应页面        |
| ----------------------- | ------------------------------------------------------- | ------------------------------------------- | ----------- |
| **Task 任务**             | 任务领域 `domain`、任务类型 `task_type`、任务标题、目标与产物、关键任务起止位置、关联会话 | 复杂度可作为辅助标签；新颖度、精细的开放程度评分暂缓                  | 画像、轨迹、项目、语义 |
| **Instruction 指令／控制方式** | 执行授权 `requested_autonomy`、先规划还是先做、核验要求、操作范围与禁止事项、验收标准   | 明确表达的详略、格式、工具偏好可以保留；约束密度、prompt 具体程度的综合评分暂缓 | 画像、轨迹、摩擦分析  |
| **Interaction 交互行为**    | 用户消息意图、人工介入位置、纠偏次数与比例、重复强调要求、摩擦类型                       | 单独的追问率、执行／讨论比例暂缓；需要时可从消息意图计算                | 概览、画像、轨迹、语义 |
| **Preference 主观偏好**     | 用户明确表达或确认的偏好、适用任务／项目、证据、发生或变化时间                         | 隐式偏好排序、完整偏好向量、推荐匹配参数暂缓                      | 画像、语义       |
| **Respond Agent 回应与执行** | 轮次数、工具调用序列、调用结果、失败原因、重试关系、子代理关系、实际并行区间                  | 回滚、上下文重启有明确记录时保留；分叉本身先作为关系字段                | 轨迹、工具、项目、画像 |
| **Cost / Time 用量与时间**   | 输入／输出／缓存 token、执行起止与耗时、会话跨度、按日和小时的活动分布                  | 实际费用、估算费用、到首次验收的时间、真实人工投入时长暂缓               | 概览、轨迹、工具、项目 |
| **Outcome 主观结果**        | 用户接受／拒收、用户确认的完成状态、返工反馈及对应对象                             | 最终是否在外部实际使用、长期满意度暂缓                         | 轨迹、项目、摩擦分析  |
| **Outcome 客观结果**        | 测试／构建／检查结果、验收项是否通过、结果证据                                 | 没有验收依据时不生成“客观任务成功率”                         | 轨迹、工具、项目    |
