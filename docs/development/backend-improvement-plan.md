## 模型与效用边界

需要语义模型时使用用户指定的 Codex 6.1 Sol、medium；限定候选、上下文长度、输出结构、预算与重试次数。
确定性事实不交给模型判断。没有标注的真实历史只能证明解析与关系的覆盖，不能证明语义准确率。
推荐效用须用相同任务、相同检查点和预算的干预对照证明；仅凭历史日志不得宣称节省 Token 或提升成功率。
缺少检查点、对照执行或人工标签时明确列为缺少证据，不能用代理指标替代实测效用。
