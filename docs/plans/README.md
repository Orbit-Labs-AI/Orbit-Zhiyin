# 后续方向与决策

本区记录还需要讨论或验证的方向，不表示已承诺的版本范围或日期。当前能运行的能力见[产品边界](../product/scope.md)，实现入口见[模块表](../architecture/module-map.md)。

| 方向 | 需要解决的问题 | 可接受的验证 |
| --- | --- | --- |
| 来源覆盖 | 上游新格式、父子会话、工具状态与增量边界 | 带版本的最小样本、兼容回归与覆盖诊断 |
| 分析可信度 | 语义标签、人格稳定性与小样本解释 | 独立标签、反例、范围隔离和误报漏报 |
| 推荐效用 | 建议能否改善后续任务 | 过去到未来的隔离评测与实际使用反馈 |
| 原生交付 | 安装、公证、系统行为与升级体验 | 冻结包及目标系统上的明确验收 |
| 社区扩展 | 新来源、新资源与文档可发现性 | 清晰契约、许可依据、构造样本与最小 PR |

新提案写清问题、目标用户、输入输出、与现有能力的关系、最小验证及尚未确定的取舍。由维护成员共同确认 MVP 范围后，再进入实现；不要把旧 feature 编号的存在解释成产品承诺。

旧的模块方案、309 项 UI 功能映射、分工、真实数据验证及扩建记录集中在[历史方案](../archive/plans/README.md)。它们保留了设计依据，但其中的“当前”“待完成”仅指原文基线。

- [路线图](roadmap.md)：已走过的阶段、进行中的工作和待商定的下一阶段里程碑；草案，待 MVP 确认成员核对。
- [历史轨迹技能学习的设计与实现记录](history-skill-learning.md)：按文中基线核对，不将其阶段目标视为已完成效果。
