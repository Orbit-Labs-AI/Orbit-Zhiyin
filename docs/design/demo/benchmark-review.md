## 数据与操作边界

- 470 个确定性的示例历史会话，时间截至 2026-09-30；默认 30 天包含 186 个会话。全部数据沿用并扩展原版模拟样本，不读取真实日志。
- 日期、Agent、项目筛选共同影响统计、会话和图表。月度画像单独使用当前 Agent / 项目的完整历史，并在页面标明，不随顶部日期截断。
- 协作时长是会话时长之和，含并行重叠。纠偏率是纠偏消息 / 用户消息。子代理调用数来自 Task 调用，不代表去重代理数量。
- 人格少于 30 个会话不定型，维度在 45–55 时显示不确定性。自定义四字母协作画像不是心理测评。
- 项目完成度使用 `(完成会话 + 0.5 × 部分完成会话) / 会话总数` 作为示例指标，不等同于真实项目进度。Token 不能直接等同费用。
- 语言特征、反馈词频、失败原因、资源匹配与预期效果均为示例。转移矩阵是标注清楚的固定样例；项目配置覆盖是示例快照。
- 同步仅演示处理固定样本的状态变化；不扫描文件、不添加虚构新会话。
- 安装先展示预览和目标 Agent，再确认模拟安装，仅在浏览器保存标记，可撤销。不会修改真实配置、执行命令或调用外部模型。Agent 定制是当前页面内可编辑的草稿，不会自动生成或发送内容。
- 导出 Markdown / CSV、保存 SVG 分享卡是真实文件下载。分享文字与分享卡不含会话原文、项目路径或用户标识；不会上传或发布内容。
- 外观与模拟安装标记使用独立的 `tandem-benchmark:` 本地存储前缀，与原版互不干扰。存储不可用时，页面仍可使用。
