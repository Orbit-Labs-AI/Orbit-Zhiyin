## Lite 与 Advance：同一个 App

| 部分 | 做法 |
| --- | --- |
| 切换 | 侧栏顶部 Lite \| Advance 滑块；「显示」菜单、命令面板、⌃⌘L 同样可切。滑块先移动，再以 View Transition 交叉淡入侧栏与内容；选择会被记住 |
| 路由 | 概览、画像、会话、建议两版一一对应，切换时停在对应页面；Lite 中打开工具、项目、情绪、资源库、工坊等 Advance 独有页面时自动切到 Advance，并给出「回到 Lite」 |
| 共用组件 | 侧栏（分组、导航行、Agents、页脚索引指示灯与用户行）、标题栏 `tbar`、卡片与栏目标题、KPI、`seg` / `chip` / 按钮、建议卡、会话行、协作指纹、桌面小组件、悬浮组件与菜单栏 |
| Lite 四页 | 概览（AI 一句话 + 大字人格码、四个大数字、30 天活跃条、本周最值得做的一件事）、协作画像（超大四字母码、表盘、四条大刻度、月度演变）、会话轨迹（最近关键会话 + 关键步骤时间线）、优化建议（前三条大卡，可应用 / 撤销）。不显示筛选行，只保留时间范围；有 Advance 筛选时给出「清除」 |
| 共用动效 | 换页时区块依次上浮淡入、`data-count` 数字滚动、标题栏下的「这页回答」导读（可收起并记住）、按钮按下回弹、可点卡片抬升、分段控件滑块、筛选 chip 增删；`prefers-reduced-motion` 时全部关闭 |
| 协作人格表盘 | 画像页中央的图。**外框**：一圈细线与 128 道刻度，按 16 型排成 16 个扇区（格雷码顺序，相邻两型只差一个字母；右半委托 D、左半掌舵 S、上半即兴 I、下半规划 P，DIMV 在 12 点右侧），不写方位文字，每个扇区在刻度内侧标自己的类型码（DIMV 等，SF Pro Rounded、正立、小而浅灰；你的类型加粗墨色，外侧 `--orbit` 三角指向它；窄窗口里的 Lite 小表盘码不足 8 px 时只留你的类型码）。**轨道**：每个会话按它自己的四个维度（与人格同一口径，只看这一个会话和它所在的那一天）归到最接近的类型，再沿扇区朝软归属更多的一侧偏一点得到连续方位；**每个 Agent 一条独立的曲线**，不叠加：各自从同一条基线长出，高度 = 该 Agent 在这个方位上的会话密度，所有 Agent 共用一个高度尺度，所以高低可以直接比；曲线之间可以重叠，半透明低饱和填充 + 一条细边，会话多的 Agent 先画、少的后画。点击某一型展开偏向它的会话点（半径 = 典型程度）。**Agent 徽章**：每个有会话的 Agent 一枚（lobe-icons 单色标志，纸色圆底 + Agent 色细环），停在曲线外的同一条轨道上，方位是该 Agent 全部会话方位的圆周平均（不吸附扇区、不找峰，一般不在曲线峰上）；碰到别的徽章或类型码时沿轨道最小幅度错开，悬停提示报它平均偏向的类型。**内盘**是协作人格之花：16 型各一朵，N 片（3–6）相同的墨色主瓣均匀围着花心，可再加一圈 N 片浅灰小瓣（错开半格），旋转对称、没有领瓣；委托 D 瓣长花心小 / 掌舵 S 瓣短而宽花心大，即兴 I 同向旋卷 / 规划 P 直，多线 M 5–6 瓣 / 专注 F 3–4 瓣，求证 V 花心是一圈环加中心点 / 信任 T 是实心点；整朵花旋转到一片主瓣指向你的类型。每型的花形与读法见[人格素材](persona/README.md)，算法说明的 16 型表同附。进入画像页时花阻尼晃动、轨道扫描展开、徽章从 12 点运行到各自的平均方向 |
| 人格之花的其他位置 | 同一套花形（`bloom()`）画在：侧栏用户行（14 px）、概览的人格卡（40 px）、菜单栏面板与桌面小组件、分享卡、算法说明的 16 型表（每型附花形读法）；浅灰小瓣的颜色是 token `--petal2`（深色比 `--h2` 亮一档）。小花放在可点击的位置（小组件、分享文案行、算法说明的表格）时，悬停会轻转一下（`43-bloom-motion.css`）。人格代号（DPMV 等）在所有页面统一用 SF Pro Rounded（`.tcode`），文字里夹带的代号由 `tcodes()` 套上 |
| 人格切换动效 | 所展示的类型变了（换时间范围、筛选、月份，或 Lite ↔ Advance 切换时两边类型不同）：旧花朝新类型转动并收向花心（约 350 ms，瓣同时旋 28°，浅灰小瓣晚 50 ms），花心在收拢处换样（环 ↔ 点），新花从花心绽开（260–860 ms，一边继续转到位，一边把旋卷退回去，略过冲后落定；浅灰小瓣晚 80 ms），码里换掉的字母随绽开升起。同时各 Agent 的曲线平滑变形到新的形状（新增的淡入、消失的淡出），徽章沿轨道走最短弧滑到新的平均方向（标志始终正立），`--orbit` 三角转向新类型，外框 16 个类型码不动、只有强调从旧类型移到新类型。类型没变但数字变了，花只做一次轻微的回弹；什么都没变的重绘（悬停、展开某一型）不播放。小花（菜单栏面板、小组件、分享文案、算法说明）与分享卡里的花用同样的收起 / 绽开，更快（收 170 ms）；侧栏用户行、概览人格卡与画像页大码的字母同样逐个升起。首次启动的 Genesis 播放期间不触发。`prefers-reduced-motion` 时新花淡入（160 ms），其余即时。实现在 `src/js/38-bloom-motion.js` 与 `src/styles/43-bloom-motion.css` |
| 首次启动 Genesis | 以 Orbit 母题连续播放约 6.7 s：倾斜的 Orbit 轨道翻正成表盘外框（细线 + 刻度）、标志内弧收拢成 12 点方向那片主瓣的中线，合拢的花苞快转、会话粒子沿轨道螺旋汇入 → 花苞匀速扫一圈、会话粒子落到各自最接近的类型，每个 Agent 的曲线在扫过处长出、Agent 徽章随扫描依次出现并公转，扫完滑到各自的平均方向 → 花苞开成该类型的花、字母翻牌锁定、花摆到一片主瓣指向你的类型，外框上的 `--orbit` 三角此时才出现（早出现会剧透类型）→ 相近人格卡比对并入 → 「查看完整画像」时人格码与表盘飞到当前版本的画像页。可随时跳过、Esc、在后台继续；「播放人格揭晓」复用后四段（约 4.9 s） |
| 分享卡 | 每个时间长度一张：近 7 / 30 / 90 天、全部（人格页在看某个月且与近 30 天不同时再加这个月）各自按窗口算人格，所以同一个人可以在周卡和全时卡上是不同类型。卡上依次是标签胶囊（周卡 WEEKLY / 月卡 MONTHLY / 季卡 QUARTERLY / 全时卡 ALL TIME / N 月卡）与日期、带活跃日历环的花（每格一天，超过 92 天每格一周，深浅 = 会话数；花与 App 里同一画法：V 型花心是环加中心点、T 型是实心点，浅灰小瓣用卡面自己的一档灰，深色卡里比日历空格提亮一档）、SF Pro Rounded 类型码与四轴强度、类型名与人格描述、会话 / 活跃天数 / Agent / 对话轮次与一行页脚；版式以留白为先，16 型各自的金句放进「复制分享文案」，不上卡。预览（SVG）与 1080×1350 PNG 执行同一份绘制指令；「全部保存」逐张导出，文件名 `orbit-persona-<7d\|30d\|90d\|all>-<code>-<日期>.png`。App 里每张卡来自 `POST /v1/export/share_card`（`period` = 该长度），网关不可用时退回 App 本地算出的人格 |

## Advance 页面与桌面组件

Demo 把主应用、菜单栏面板、悬浮组件、桌面小组件和关键流程放在一个模拟的 Mac 桌面里。切换时间范围、Agent、项目或筛选条件后，各页面的数字、图表和人格一起变化。

| 部分 | 可以操作的内容 |
| --- | --- |
| A1–A9 九个页面 | 筛选与对比、图表 ↔ 表格、热力图下钻、轨迹回放与拖动播放头、双会话对比、工具明细排序与展开、跨项目回归散点、情绪曲线、建议分级与教程、资源库匹配度、生成工坊的分步运行 |
| 菜单栏 | 「Orbit / 文件 / 显示 / 窗口 / 帮助」菜单，右侧 Orbit 图标打开菜单栏面板（运行中、空闲、需要关注三种状态） |
| 悬浮组件 | 五种收起态；点击展开、拖动吸附到 6 个位置，按住 ⌥ 自由放置 |
| 桌面小组件 | 宽度 ≥ 1500px 时默认显示，窄屏时在「显示」菜单中打开 |
| 流程 | 安装闭环（预览 → 确认 → 10 秒撤销 → 7 天效果追踪）、首次启动、人格揭晓、分享卡、导出报告与 CSV、命令面板、问本地 Agent、设置窗口六个分区 |

### 滚动区域

主从分栏并排时（内容列 ≥ 800px；项目习惯 ≥ 1100px），页面本身不滚：「这页回答」与筛选行固定，分栏填满窗口剩余高度，每个窗格各自滚动，滚到头也不带动外层。分栏堆叠的窄窗口退回整页滚动。样式在 `src/styles/88-panes.css`，选中项保持可见在 `src/js/88-panes.js`，用例见 `tests/p-pane-scroll.spec.mjs`。

| 页面 | 滚动区域 |
| --- | --- |
| 会话轨迹（两版） | 会话列表（搜索头固定，只滚行）｜ 会话详情 |
| 优化建议 | 建议卡列表 ｜ 建议详情 |
| 项目习惯 | 项目表 + 散点 ｜ 项目详情（内容列 < 1100px 时堆叠，整页滚动） |
| 生成工坊 | 新建任务 ｜ 运行 ｜ 产物三张卡各自滚动（800–999px 时产物卡移到运行卡下方）；「开始生成」固定在任务卡底部 |
| 概览、协作人格、情绪语义、工具调用、资源库、Lite 概览 / 画像 / 建议 | 一列堆叠的卡片，保持整页滚动 |
| 设置窗口、sheet、菜单栏面板、首次启动 | 设置的分区标签固定、正文滚动；sheet 的标题与按钮固定、正文滚动，导出分享卡的预览与选项两栏各自滚动 |

- 菜单栏右侧的 **「演示」** 菜单可以模拟会话完成、等你确认、连续失败、上下文即将压缩、每周报告、发现新数据源，以及切换空闲状态、重播首次启动与人格揭晓、重置数据。
- 快捷键：⌘K 命令面板，⌘, 设置，⌘⇧S 分享卡，⌘⇧E 报告，⌥⌘P 悬浮组件，⌃⌥T 菜单栏面板，Space 回放轨迹，? 查看全部。浏览器占用的组合在 Demo 中改用 ⌥（如 ⌥1–⌥9 切换页面）。

## Lite 原稿（genius-FXC）

- 沿用暖白底色、衬线标题、等宽数字、侧栏和 Agent 配色，按个人协作 Benchmark 的需求收敛为八页：概览、协作画像、会话与轨迹、工具调用、项目分析、情绪与语义、优化建议、资源库。
- 不含生成工坊、桌面小组件、悬浮面板、首次启动、人格揭晓、会话回放 / 对比和通知模拟；保留全局搜索、浅深色、筛选、同步入口、导出与分享。
- 日期、Agent、项目筛选共同作用于各页；Markdown 报告、会话 CSV 与 SVG 分享卡支持真实下载；同步、安装和社区推荐均为明确标记的演示。
- 可运行的 Lite 已并入统一 App；原稿保留为设计来源，检查命令见 [lite-review.md](lite-review.md)。

## 修改 Demo

`prototypes/advance/orbit-demo.html` 是构建产物，**不要直接改它**：源码在 [`prototypes/advance/src/`](../../prototypes/advance/src/)，下一次构建会覆盖对产物的直接修改。

- `src/index.html` 是页面骨架，`/*@css*/` 与 `/*@js*/` 两个占位符各出现一次；`src/styles/*.css` 与 `src/js/*.js` 按文件名排序后拼接进去。
- 文件名必须是 `NN-名称.css` 或 `NN-名称.js`，两位数字前缀决定拼接顺序；`00-utils.js` 必须排在第一位，它开头的 `"use strict"` 对整段脚本生效。
- 后面的文件会改写前面文件里的同名函数：`80-history.js` 改写 `go` 并包装 `ACT.studioStart`，`42-a3-sessions.js` 改写 `base`。改这些函数时两处一起看。
- 版本切换与路由映射在 `26-edition.js`，Lite 四页在 `39-lite-pages.js`，两版共用的动效在 `37-motion.js`，Orbit 标志在 `00-utils.js`。
- 测试用系统里的 Google Chrome（`channel: 'chrome'`）；没装时先运行 `npx playwright install chrome`。浏览器测试细则见 [`prototypes/advance/TESTING.md`](../../prototypes/advance/TESTING.md)。

| 命令（在 `prototypes/advance/` 下运行） | 作用 |
| --- | --- |
| `pnpm build` | 由 `src/` 生成 `orbit-demo.html`（仓库根可用 `pnpm --filter @orbit/prototype-advance build`） |
| `pnpm check` | 检查提交的 `orbit-demo.html` 与源码一致，提交前必须通过 |
| `pnpm test` | 构建后跑 Playwright：各页面在 6 种窗口尺寸下的渲染与横向溢出，以及浮层、菜单、模拟事件和快捷键 |
| `pnpm test:ui` | 只在 mac-14 尺寸下构建并测试 |
| `node tools/shoot.mjs --sizes mac-14,compact --full`（`--ed lite` 拍 Lite 四页） | 截图到 `shots/`（不提交），用于目视检查 |
| `node build.mjs --artifact <文件>` | 生成发布到 claude.ai 的版本（去掉 doctype、html、head、body 行），再发布到上面的在线 Demo 地址 |

仓库根的 `pnpm check:ui` 同时跑 Lite 数据检查与 Advance 浏览器测试。源码与产物一起提交；PR 中 `orbit-demo.html` 的差异会被折叠（见仓库根 `.gitattributes`）。
