# 设计与展示素材

Orbit 的设计围绕同一个 App 的 Lite / Advance 界面展开。Lite 设计来自 `genius-FXC`，Advance 来自 `yhyfhgs`；二者共享组件和数据。当前界面上两版已合并为一套侧栏（高级模式切换完整明细布局），Lite 保留全部入口，对页面数量与尺度做减法。

| 需要什么 | 入口 |
| --- | --- |
| 名称、标志、图标、字标与字体 | [品牌](brand.md) |
| 当前可运行界面与修改方式 | [Demo 与界面](demo.md)、[prototypes](../../prototypes/README.md) |
| 早期画板及其与实现的关系 | [画板](boards.md) |
| 16 型花与表盘 SVG/PNG | [人格素材](persona/README.md) |
| 路演页面和独立组件导出 | [PPT 素材](ppt-assets/README.md) |
| README、介绍和分享用图片 | [展示图](showcase/README.md) |
| 宣传片的源码与分镜 | [promo](../../prototypes/advance/promo/README.md) |

标志参数只在 `logo/orbit-spec.json`，资产从素材包原样引用；不在 App、网页或 PPT 中另画一条相似曲线。人格与界面截图来自当前原型，引用时注明示例数据。

画板记录设计，不保证全部功能已发布；实际数据含义以[展示指标](../modules/analytics/presentation-metrics.md)和[产品边界](../product/scope.md)为准。设计演变和 Lite 原稿审查保留在[设计历史](../archive/design/README.md)。返回[文档首页](../README.md)。
