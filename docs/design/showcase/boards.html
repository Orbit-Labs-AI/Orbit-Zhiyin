01　协作人格罗盘
一张图，读懂你怎么和 Agent 协作
每个会话按它自己的四个维度落到 16 型之一；外圈是会话的分布，花心是你的类型。
1三角 · 你的类型

指向你在这段时间里的协作人格。示例是 DIMV 指挥家：委托、即兴、多线、求证。

2外框 · 16 种协作人格

16 个扇区按格雷码排列，相邻两型只差一个字母：右半委托、左半掌舵，上半即兴、下半规划。

3轨道 · 每个 Agent 一条曲线

会话落在哪一型，就在那个方位隆起；越高会话越多。所有 Agent 同一基线、同一尺度，可以直接比高低。

4人格之花 · 你的类型的花

16 型各一朵：瓣数、瓣形和花心由四个字母决定，整朵花转到一片主瓣指向你的类型。

5徽章 · Agent 的平均方向

Claude Code、Codex、Gemini CLI……各停在自己全部会话的平均方向，看出你和每个 Agent 分别怎么配合。

02　四个维度 · 16 种协作人格
四个字母，拼出你的协作人格
每个维度取一极，组合成 16 种类型；花形由字母决定，看花就能认出类型。
D委托/S掌舵
你把多大块的事交出去？
花：委托瓣长、花心小；掌舵瓣短而宽、花心大
I即兴/P规划
先想清楚再动手，还是边做边想？
花：即兴的瓣同向旋卷，像风车；规划的瓣是直的
M多线/F专注
你同时推进几件事？
花：多线 5–6 瓣，专注 3–4 瓣
V求证/T信任
你怎么确认它做对了？
花：求证的花心是一圈环加中心点，信任是实心圆点

03　工作原理
从本机会话日志，到下一步该装什么
1找到会话

自动发现本机各个 Agent 的会话日志，只读取，不碰凭据；取消勾选的来源不会被索引。

2在本机整理

原始日志不可变归档，统一成同一套事件，再派生出会话、步骤、工具与情绪数据。

显式启用来源只读
↓
不可变归档可回看原文
↓
统一事件跨 Agent 同一口径
↓
派生数据会话 · 步骤 · 工具
↓
画像与特征分析四个维度
3看见自己

协作人格与它的依据；每个会话的轨迹、关键时刻，以及工具、项目和情绪。

会话轨迹工具调用项目习惯情绪与语义
4动手改进

每条建议附依据和预计节省；预览后一键写入，随时撤销，7 天后对比效果。
