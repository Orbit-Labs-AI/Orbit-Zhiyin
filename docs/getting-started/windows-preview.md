# Windows 预览版（0.0.5）

> 这是随 **Orbit 0.0.5** 提供的 Windows 预览版，独立于 macOS App 构建。
> 目标：在 Windows 上以同一套新版界面查看本机 Agent 会话的只读统计，验证 Windows 端交互与真实数据链路。

## 它是什么

- 一个本地桌面窗口：**Node 网关 + Microsoft Edge `--app` 窗口 + 原生桥**，零第三方依赖（不安装 Electron / Tauri）。
- 界面与 macOS 版使用同一套新版合并版式 / 中英双语界面（Lite / Advance 合并侧栏、命令面板、设置、资源库等）。
- Windows 适配：Segoe UI / 微软雅黑、Cascadia Mono；⌘→Ctrl、⌥→Alt、F11 全屏；Finder→文件资源管理器；
  `~/…`→`%USERPROFILE%\…`；真实窗口最小化 / 最大化 / 关闭；真实保存 / 选择文件夹对话框；偏好持久化。
- **首次启动空白 → 扫描运行者自己的会话**：应用启动时页面是空白；随后只读解析**运行者这台电脑**上的
  Claude Code / Codex / DeepSeek Harness 会话日志（只统计时间、轮次、工具调用、错误、token、标题；**不读正文、不上传**），
  完成后页面自动刷新显示会话 / 项目 / 画像 / 概览。**发布包内不含任何会话数据、真实标题或真实截图**；
  每台电脑首次启动都会扫描自己的日志。子代理 / workflow / 队友会话会被过滤。

## 怎么安装 / 打开

1. 解压 `Orbit-0.0.5-windows-x64.zip` 到任意目录（例如 `D:\Orbit\`）。
2. 双击 `Orbit.exe`（无控制台），或 `启动 Orbit.vbs`；调试可用 `Orbit.bat`（保留日志窗口）。
3. 首次启动为**空白**；随后自动扫描本机会话日志（约 3 秒），完成后窗口自动刷新显示运行者自己的数据。
4. 关闭窗口即整体退出；双击 `StopOrbit.exe` / `停止 Orbit.bat` 可停止后台。
5. 新开会话后：`Ctrl+K → 重新索引`。

依赖：Microsoft Edge（系统自带即可）与 **Node.js 26+**。默认使用 `D:\Codex\Orbit\.tools` 下工作区自带的 Node；
如果拷贝到别的电脑，请安装 Node.js 26+（或把工作区 `.tools` 目录一起带上）。

## 与 macOS App 的关系

- 同一套 UI 源码 / 生成物与新版界面；**不是** macOS App 的等价移植：Windows 预览版没有 Python 分析 / 推荐 / 安装后端。
- 数据层的时区修复（`packages/data`）只影响 Python 后端；Windows 预览版是独立 Node 构建，不包含该数据层。
  若后续把 Python 数据层搬到 Windows，需要把 `tzdata` 加入依赖并打进产物，否则 IANA 时区会被静默降级。
- 安装包内部版本标记为 `0.1.0-preview`；发布资产名使用 `0.0.5` 以对应本次 Release。

## 已知限制

- 建议 / 资源库 / 工具明细为示例数据；真实推荐后端未接入。
- 需要 Node 26+，不是单文件绿色版；任务栏与窗口标题栏使用 Edge 的图标 / 标题栏。
- 轨迹曲线与画像是统计近似；样本少时页面会标注「数据越多越准」。
- 全屏退出在窗口未聚焦时可能延迟，按 **Esc** 退出。
