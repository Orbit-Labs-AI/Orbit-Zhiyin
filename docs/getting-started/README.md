# 开始使用 Orbit

Orbit 帮你把本机 Agent 会话整理成可回看的协作记录、分析和改进建议。选择一条适合自己的路径：

| 你想做什么 | 从这里开始 |
| --- | --- |
| 在 Mac 上使用 | [安装桌面 App](installation.md) |
| 不导入个人数据，先看效果 | [体验示例](demo.md) |
| 选择来源并看第一次分析 | [导入会话](../guides/importing-data.md) |
| 修改代码或接入模块 | [开发环境](../development/setup.md) |

桌面 App 面向 Apple Silicon、macOS 14 及以上。Orbit·知音已于 2026-10-14 停止开发；本文档跟随 `main`，下载版本的能力和已知问题以对应 Release 说明为准。

返回[文档首页](../README.md)。
