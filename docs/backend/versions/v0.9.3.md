# v0.9.3：读懂工具包装，保留未知状态

当前 Codex 的 `exec` 把多条工具结果包装成一次返回。读取器现在识别包装中的完整命令元数据，区分脚本出错、命令退出码和未知返回；不会因为“脚本完成”就认定所有命令成功，也不会扫描 stdout 中的错误示例。

每条状态保留来源层级。混合批次中有明确失败时记录失败；缺退出码或返回无法核对时保持未知。只有调用源码中确有命令接口提示，才解析包装里的命令结果；源码只做检查，不执行、不保存。

116 项检查通过，覆盖混合批次、仍在运行的命令、布尔假退出码、stdout 里的伪失败和三次真实失败的完整推荐链。固定样本已重新导入，新增识别出旧版本看不到的失败；真实推荐仍取决于画像与具体卡点，没有随失败计数自动增加。

下一步准备读者对照验收，并继续复核数据分组与报告中的判断依据。某些旧格式只输出简化结果，状态仍无法确认。
