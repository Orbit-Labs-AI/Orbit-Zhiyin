# v0.10：让读者评价与规则检查各自负责

现在能生成两份顺序相反的阅读材料和空白评分表。两种表达使用同一组事实，不显示版本名；读者先复述重点，再评价主次、背景适配、中文语感和事实保留。

这是独立的评价模块。它冻结材料与版本映射，拒绝把修改后的正文和旧评分混在一起，也不会覆盖已填表格。缺少评分时保留未知；只有读者明确声明，才记录这批案例的验收结论。

159 项测试通过，三组自动对照仍通过。六类虚构案例已生成；同一份真实分析的旧版和当前表达也已在本地生成。真实阅读结果仍为空白。尚未验证资源能改善输出，这个模块只是让下一步评价可以复现。

使用方法见 [读者评审](../reader-review.md)。接下来继续检查真实报告的阅读顺序，并把数学统计的含义与边界单独讲清楚。
