# v0.11.3：保留当前任务的意思

“预期失败测试已经完成，现在运行正常测试”不再屏蔽后续失败记录。过去的负例测试说明会被排除，当前明确要求负例测试时仍不生成调试建议。相同参数连续失败仍只是候选卡点，不能证明浪费了时间。

同次交付先给文件链接、后给正文时，会合并核对正文是否出现，清除过早生成的正文缺失提示。新用户请求会结束前一次交付，片段和截断内容仍保留限制。识别到正文只证明日志有可检查的内容，不能证明写得好。

215 项测试与三组自动对照通过，真实样本报告重新生成。剩余验收重点是读者能否理解报告、复述主次，以及推荐试用前后是否改善实际任务；这部分需要真实读者，不能由规则分数替代。
