# v0.2.1：修正快照与需求理解

这次采纳三条新的 Codex review 意见，让分析输入更可靠。

固定历史快照时，缺失或无效时间戳的事件不再进入样本；模型只从快照内可见的记录恢复。语言选择读取“请用中文解释”这类明确要求，讨论 English API 不会自动切成英文。数据字段里的“来源”也不再直接变成“用户要求证据”的画像信号。

19 项后端测试与 lint 通过，新增回归检查覆盖这三种情况。每次改变解析规则都会更新导入版本，旧派生记录按新规则重算，避免修正只对新文件生效。

完整数据流和推荐关系沿用 v0.2。下一步继续完成资源来源的可复现获取，以及更贴近实际任务的评价；自动检查仍不代表读者已认可结果。
