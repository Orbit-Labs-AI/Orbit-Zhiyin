# v0.11.4：篇幅限制跟着交付内容走

“分析这三段话”不再成为简洁偏好；“用三段话说明”仍保留为输出要求。摘要与正文的限制分开保存，支持顿号分隔。正文需要可识别的分界，否则提示无法核对，避免把未知算成通过。

同次交付分成多条回复时，按整体核对限制，保留每一条证据。合并时加入的分隔符不计字数。截断记录优先用导入时保留的完整统计，无法确认时保留未知。分析 JSON 版本升为 1.6，篇幅对象增加 `body`。

228 项测试与三组自动对照通过。新增完整流程用例覆盖原文段落引用、两种篇幅要求、恰好达到上限、跨条超限、截断统计和新任务边界。下一步完成干净安装、API 验收和读者材料，保持真实评价待填写。
