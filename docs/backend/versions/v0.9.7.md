# v0.9.7：瓶颈判断保留任务原意

“修复后运行预期失败测试”里的失败不再触发排错建议。判断按分句读取预期，仍保留“测试不应该失败”等真正需要回看的情况。

连续工具失败现在沿用当前任务的场景、读者和交付语言。写报告时的失败可以在报告场景中查到，但现有排错资源只适用于代码协作，因此不会硬塞一条建议。矩阵乘法函数实现的失败则能正常关联代码要求与排错资源。

文件交付也要求明确的完成表述。“计划保存”“无法写入”不算已经交付；“已将文件重写为英文稿”等中文句式仍可识别。识别交付只能说明日志缺少正文，不能据此评价文件写得好不好。

148 项测试和三组自动对照通过。真实样本仍保留两处说明修改记录、一条资源试用建议。下一步把相同事实下的不同表达做成读者评审材料，检查主次、自然程度与读者是否能复述要点。
