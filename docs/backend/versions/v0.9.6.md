# v0.9.6：先判断一句话是在要求什么

这版修复了几类会影响画像和推荐的误读。例如，“保持‘简洁直接’”是写作要求；“解释‘简洁直接’这个词”只是讨论词义。“实现已经完成”是在汇报状态，也不能记成要求执行。

读者和场景同样按当前任务判断。明确排除的读者不再沿用；矩阵乘法函数的实现归入代码协作，数学证明仍归入数学讲解。独立出现的“回答不超过 100 字”现在也能进入篇幅核对和推荐链路。

133 项测试通过，三组自动对照仍分别通过 8、34、12 个案例。固定历史样本仍得到两处说明修改记录和一条有证据的资源试用建议，没有因此增加推荐。自动对照只能验证这些规则，不代表读者已经认可。

下一步修复瓶颈判断：区分预期失败与修复失败，保留失败发生时的任务场景，并避免把计划保存文件误写成已经交付。
