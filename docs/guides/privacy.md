# 隐私与数据

Orbit 将会话索引、基础统计和应用状态保存在本机。来源导入需要明确启用；AI、资源同步和安装获取有各自的数据与联网边界。

## 什么存在哪里

当前源码默认使用 `~/Library/Application Support/Orbit`；`ORBIT_HOME` 或 CLI 的 `--home` 可以选择独立目录。

| 内容 | 位置与用途 |
| --- | --- |
| Agent 原始记录 | 由 Agent 自己管理；Orbit 原生扫描保持只读 |
| `orbit.db` | 来源索引、标准事件、会话及派生事实 |
| `raw/` | 使用归档或桥接流程时保留的原始内容；不是每种原生扫描都复制原文 |
| `app.db` | 设置、任务、授权、推荐和安装等应用状态 |
| `catalog.db` | 资源目录、检索投影与可选向量 |
| `analysis.sqlite` | 分析运行与结果快照 |
| 日志与导出 | 排障信息和用户主动生成的报告；可能包含敏感内容 |

索引不是独立备份。原文读取可能依赖仍存在且版本匹配的源文件；备份 Orbit home 也不一定包含所有来源原文。

## 哪些操作可能联网

基础导入和确定性分析不要求远端模型。目录同步会访问资源来源；安装时显式获取资源可能下载内容；启用 AI 后，本地 Agent 或所选引擎可能调用远端模型。上下文包按授权类别构建并脱敏，仍应在提交前检查。

App gateway 监听 loopback，使用每次启动的 Bearer token 与 Host/Origin 校验。报告 API 是独立开发入口；不要将它当作可直接暴露给公网的服务。

## 暂停、排除与删除

暂停采集停止后续采集，不自动删除已导入内容。把会话排除出分析只改变分析样本，也不等于删除来源或导出。数据清理应按 App 展示的范围确认；安装撤销和会话清理是独立操作。

如需备份或人工管理本地数据，先退出 App 和相关服务，再处理整个数据目录。卸载 `Orbit.app` 通常不会删除 Application Support 中的数据；Agent 自己的原始记录也不属于 Orbit 安装目录。

## 分享报告与问题

分享前检查正文、截图、路径、用户名、项目名称、代码、工具参数和凭据。自动脱敏是防护层，不能保证移除所有可识别信息。仓库只接收构造或充分脱敏的样本，不接收真实会话库或 `.env`。

安全问题按[安全政策](../../SECURITY.md)报告。返回[使用指南](README.md)。

可选本地检索模型也涉及一次授权后的权重下载；推理使用本地权重，与向远端模型发送会话上下文是不同的数据流。
