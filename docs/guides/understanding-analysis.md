# 理解分析结果

Orbit 的分析从当前选中的会话事实出发。阅读一张卡片前，先看时间窗口、项目、Agent、样本量、数据覆盖与更新时间；换一个范围，分母和结论都可能改变。

## 从页面回到证据

概览适合观察变化，会话轨迹适合解释具体事件，工具调用与项目习惯适合找重复模式。协作人格用四轴与 16 型描述当前样本中的协作行为；它不用于判断心理健康、能力或固定身份。情绪语义页面描述记录中的表达，也不能直接推断人的内在状态。

看到某个异常或建议时，打开对应会话、工具调用或证据，核对发生时间与上下文。少量样本、未知状态和未记录的行为都会限制解释。

## 空白、零和未知

| 显示或状态 | 应怎样理解 |
| --- | --- |
| `0` | 在已知、适用的统计口径里确实没有观察到 |
| `—` / 未知 | 缺少字段、配对或可靠边界，不能计算 |
| 样本不足 | 有观测，但不足以支持稳定判断 |
| `available` | 这一类输入可读；不保证所有字段完整 |
| `partial` | 部分事实可用，仍有缺口及原因 |
| `unavailable` | 没有这类可用输入，例如尚未扫描安装清单 |
| `excluded` | 按用户选择或计算范围主动省略 |
| 更新中 / 陈旧结果 | 显示上一次可用快照，新数据尚未发布或分析尚未完成 |

## 容易误读的数字

- 工具失败率使用已知结果作为适用分母；未知返回不能算成功。
- 累计 token 快照与逐次请求计量不能直接相加；未知价格不代表免费。
- 日志时间跨度、工具耗时、审批等待和人工投入是不同概念；并发耗时也不能简单累加。
- 任务、轮次、消息和会话是不同计数单位；子代理记录不会自动成为新的真人会话。
- 推荐分数表示匹配和排序依据，估算收益不等于已经节省的时间。
