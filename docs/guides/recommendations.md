# 使用推荐与资源库

Orbit 将会话中的问题、协作偏好、当前环境和资源信息组合成建议。资源库用于浏览与检索，优化建议用于解释“为什么这项资源可能适合当前范围”。无匹配结果也是有效结果。

## 选择一次小范围尝试

1. 查看推荐依据、引用会话、适用 Agent 和资源来源。
2. 打开详情，区分匹配分数、元数据完整度、静态风险标记与实际效果。它们不是同一种评价。
3. 对支持安装的资源查看预览，核对目标 Agent、用户或项目范围、路径、内容与冲突。
4. 确认后应用。只查看、下载或生成内容不等于已安装；链接型资源可能需要按上游说明操作。
5. 使用一段时间后回看证据与反馈。如果不适用，可给出原因或使用支持的撤销操作。

安装预览和确认绑定具体内容。外部文件若已变化，撤销或再次应用可能要求重新处理冲突；不要用旧预览覆盖新改动。

## 资源与联网

目录有随包离线内容，主动同步可获取公开来源的更新。部分资源只能提供元数据或上游链接，正文与获取方式受来源和许可约束。查看资源不等于信任其脚本；执行前仍需阅读具体内容。

本地语义检索需要另行配置本地模型与向量索引。未启用或不可用时仍可使用词法和特征检索，界面应说明降级。配置方法见 [Catalog](../../packages/catalog/README.md)。

## 生成建议

“生成”候选表示可以进入生成流程，并不是已经存在的 Skill。需要先[启用 AI](ai.md)，预览输入、生成和检查产物，再决定是否安装。没有可用引擎、授权或证据时，Orbit 应保留相应原因。

技术实现见[推荐引擎](../modules/recommendation/engine.md)与[安装输出契约](../contracts/personalization-output.md)。返回[使用指南](README.md)。

模型可使用已发现的完整本地权重，或在用户明确允许后下载；首次编码与正文全量编码是不同操作，尚未完成时应保留覆盖状态。
