# 使用 AI

Orbit 默认使用 `stats` 模式，模型调用关闭。导入、基础统计、证据回看以及不依赖模型的分析可以先独立使用。

## 启用之前

在设置中选择可用引擎，检查本地 Agent 的登录状态、模型配置和授权。Orbit 通过本地进程调用 Agent，不代表模型计算一定发生在本机；该 Agent 可能把输入发送到自己配置的远端服务，并消耗对应额度。

授权按“引擎 × 数据类别”保存，可撤销。当前类别包括结构化统计、脱敏片段和规则段落；未脱敏原文类别不允许发送。自动处理新会话另有开关，默认关闭。

## 一次问答或生成

1. 选择时间、项目、来源或具体会话，确认问题针对的范围。
2. 查看上下文预览和所需授权，检查片段是否合适；自动脱敏不等于已经匿名化。
3. 提交后关注任务状态。已排队、运行中、完成、失败和取消应分别呈现。
4. 阅读结论引用的证据与限制。结构或证据校验通过不代表每个解释都正确。
5. 生成的规则、Skill 或 Hook 先作为草稿审阅，之后才进入安装预览。

## 失败与撤销授权

引擎不可用、授权不足、预算限制或输出不符合要求时，基础统计仍然可用。先检查设置和任务错误，避免连续重试同一个无效配置。撤销授权阻止后续相应调用，但无法收回此前已发送到提供商的数据。

面向开发者的协议与证据约束见[AI 模块](../modules/ai/README.md)。返回[使用指南](README.md)。
