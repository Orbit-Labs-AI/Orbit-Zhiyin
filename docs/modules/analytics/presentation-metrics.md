# 展示指标合同

展示层将已有测量转换成页面可用的单位、分母、覆盖与证据。它不得从 Demo 常量补真实结果，也不得在前端另外计算一套成功率或人格算法。

## 入口分工

`analytics/presentation` 提供确定性的特征呈现，`analytics/products` 组合分析产品，`uiview` 构造 App 页面模型。App 的类型码来自 `uiview.persona`；analytics 描述性 profile 不输出四字类型，见[画像](profiling.md)。

## 共用规则

| 项目 | 合同 |
| --- | --- |
| 范围 | 先按同一 Scope 读取事实，再计算和展示 |
| 时间 | UTC 保存，IANA 时区分桶；未知时间单列 |
| 缺失 | 已知零为 0，未知为 null，UI 显示 `—` 或原因 |
| 比例 | 返回适用分母、有效数、未知数，零分母为 null |
| 证据 | 保留事件/调用/任务身份与规则版本 |
| 新鲜度 | 显示输入版本与更新时间；陈旧、计算中、空态不同 |
| 示例 | 独立 HTML 的预设值不进入 live 事实 |

## 基础与执行指标

会话、任务、轮次、真人消息、工具调用和模型请求各按自身身份计数。主会话真人分母不被子代理放大。工具失败率只使用状态可判定的适用调用；包装成功、缺返回和未知失败原因分别处理。

工具排行区分工具类别、原名、MCP、软件命令头；不能把一个 shell 外壳当成所有内部程序。转移矩阵沿确定 seq 取相邻调用，缺序或歧义处断开；边复用率不表示失败重试。

## 用量、时间与趋势

用量遵循未缓存输入、缓存读写、输出及思考子集的契约，累计快照不与逐次值重复相加。墙钟跨度、可靠区间并集、原生执行报告、审批等待和模型延迟各自显示单位与覆盖。

比较窗口需明确边界和同一口径；基期为零或不可用时不显示增长百分比。趋势保留真实日期间距与缺口，不把未采集日期补成零活动。

## 文本、情绪与人格

词频只用经过来源与引用清理的真人文本，词数不是模型 token。表达分类只反映可识别的文字，未知不能补为中性。关键词候选、模型推断、明确标注和用户确认分开。

类型码、描述性偏好和二维坐标有不同用途。坐标用于比较当前表示，不能推出效率高低；轴的极性不能仅由“没有识别到某类要求”反推。

## 推荐与导出

排序分、风险、元数据完整度、估算收益和观测效果分开呈现。没有估算时显示未估算，同一问题替代方案不无条件累加。导出复用相同快照、范围、覆盖和单位，不能只导出漂亮的主数值而省略缺口。

路由与产物见[组合分析](analysis-products.md)，计算假设见[数字的含义](modeling.md)。
