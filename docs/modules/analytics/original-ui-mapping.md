# 页面与分析结果的对应

本页用于将设计概念映射到真实分析结果。历史画板中的样例数值与旧控件不构成数据契约；当前路由与字段分别以 `uiview`、`analytics/products` 和前端绑定为准。

| 页面 | 主要数据 | 展示边界 |
| --- | --- | --- |
| 概览 / Lite 首页 | 会话、工具、活动、趋势和推荐 | 显示范围、样本与新鲜度 |
| 协作人格 | `uiview.persona` 的四轴与类型 | 与 analytics 的描述性 profile 分开 |
| 会话轨迹 | 标准事件、调用、关键时刻与结果 | seq 顺序、缺失原文与未知状态可见 |
| 工具调用 | 配对状态、工具分类、转移与调用明细 | 工具类别与软件命令头不混为一类 |
| 项目习惯 | 规范项目与同范围特征 | 不因目录名相似合并项目 |
| 情绪语义 | 清理后的真人文本与表达信号 | 表达不等于心理状态，未知不填中性 |
| 优化建议 / 资源库 | App 推荐主栈 / Catalog | 排序、完整度、风险、效果分别解释 |

转移矩阵描述筛选后已知顺序中的相邻调用。无 seq 不推断，有歧义就在边界断开；重复边不能直接解释为失败重试。字段定义见[展示指标](presentation-metrics.md)，接口见[组合产品](analysis-products.md)。
