# v0.13.2：追问不是改写交付

> 状态：历史版本记录；描述当时行为，当前入口见仓库 README。
Agent 有时会先问“想看生活例子还是图示”，等用户回答后才改写。上一版在第一条用户消息处停止，可能把这句追问当作新版正文，漏掉实际交付和后来的相对评价。

现在，同一任务中的问答回执或对已给选项的简短选择可以继续这条链。追问与答复保留为单独证据，实际改写才进入前后正文比较。只有追问、没有改写时，状态明确为尚未交付；明确的新任务仍结束旧链。该规则先由构造场景确定，未按真实样本的推荐结果调参。

新增 5 个构造案例，覆盖普通选择、延续请求、问答回执、未回答追问和切换任务。全套 319 项测试、lint 与三组场景回归通过。下一步仍是核验正文是否保留必要事实、取得独立读者评价；当前没有把候选链直接用于偏好训练。
