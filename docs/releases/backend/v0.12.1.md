# v0.12.1：修正共同限制、任务边界和模型归属

> 文档状态：版本记录。正文保留原基线、日期与证据；其中的状态和数字不代表当前版本。现行入口见[文档导航](../../README.md)。


> 状态：历史版本记录；描述当时行为，当前入口见仓库 README。
三类边界会影响画像与瓶颈：摘要和正文共用一个上限时只检查了正文；明确换成另一个分析对象时仍继承旧任务；用户消息先于轮次标记出现时，按模型筛选可能丢掉要求。

现在，带“各、分别、均”的共同上限会展开成独立限制，合计上限保留为整体限制。“另一个公式”等新对象重新开始任务，换个例子或说明方式可以延续原任务。导入器把尚未回复的前置消息关联到随后出现的轮次和模型，不把已经回复的旧请求迁移到新轮次；固定快照不会借用未来的模型信息。

构造测试还发现“分别、特别”中的“别”不能当否定指令，已修正。新增 22 个边界案例，全套 274 项测试、lint 与三组场景评价通过。修正依据来自代码审查和独立构造案例，在运行真实样本前固定版本。

画像与瓶颈副产品沿用 [v0.12](v0.12.md) 的结构。任务边界仍是规则判断，需要回看证据；这次修正不新增人格或效率分数。
