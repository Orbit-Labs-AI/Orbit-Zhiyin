# v0.13.3：把条件、澄清和读者对象分清楚

> 状态：历史版本记录；描述当时行为，当前入口见仓库 README。
画像和瓶颈依赖文本含义。审查发现三种会增加错误证据的情况：把“如果新版更清楚，就采用它”当作已经认可；把澄清回答当作再次修改；把文章研究的对象当作读者。

现在，条件和期望表述不贡献相对评价。问答回执仍可补充明确要求，但不会独立生成针对追问的修改瓶颈。读者词需要有直接支配它的提示，或者属于该提示下的并列读者；中间的“分析”等动作会结束读者范围。这样“面向普通读者分析初学者的问题”只指定普通读者。

新增 11 个构造案例，先固定规则，再核对真实样本。全套 330 项测试、lint、8 个文字对照、34 个开发场景和 12 个措辞回归场景通过。当前方法仍是有限规则，复杂语义可能漏识别；下一步需要人工核验与独立数据，而非按某次用户样本继续调到理想结果。
