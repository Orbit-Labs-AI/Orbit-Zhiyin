# v0.13.1：让证据缺口和采集边界可验收

> 状态：历史版本记录；描述当时行为，当前入口见仓库 README。
这一版解决审查中发现的九处问题，重点是让画像与卡点的依据完整，同时避免采集边界失效。超大 JSONL 记录按有限缓冲读取；显式重设样本后，收紧范围也会先清除旧数据；没有当前模型信息的前置请求保持未知。

分析保留“各自”的共同篇幅要求，不把行内标签当成平台指令，也不把已定义术语的重复出现累计为新概念。连续失败的案卷同时引用调用与结果，可以核对参数摘要。日志只有文件交付说明时，材料缺口独立进入瓶颈报告，不依赖先找到一个卡点。

CLI 导出的证据是已标准化的本地副本，报告无需启动服务就能打开来源。重跑时清理本工具生成的旧副本；其余文件保留。瓶颈报告先呈现前三处具体记录和三处材料缺口，完整顺序仍在 JSON 中，避免把所有细节一起塞给读者。

先用虚构案例验证，再运行真实样本。新增的边界检查覆盖九处修复与离线证据；全套 314 项测试、lint、8 个文字对照、34 个开发场景和 12 个措辞回归场景通过。真实语义、长期偏好稳定性和资源收益仍需读者核验，不能由这些规则测试宣布达标。
